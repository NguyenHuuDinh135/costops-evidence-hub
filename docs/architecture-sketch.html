CostOps Evidence Hub - Sketch kiến trúc

Terraform chạy local. GitHub Actions chỉ CI/CD code bằng OIDC. Không dùng CloudFront.

Local Terraform

  • Provision S3 Website, API Gateway, Lambda, Budget, EventBridge, IAM OIDC.
  • State/credentials ở local, không chạy terraform apply trên GitHub.

GitHub CI/CD

  • Assume role qua OIDC.
  • Upload frontend lên S3 và update Lambda code packages.

No CloudFront

  • Frontend dùng S3 Static Website endpoint.
  • Lưu ý: S3 website endpoint là HTTP/public-read, phù hợp lab/demo không chứa dữ liệu nhạy cảm.
